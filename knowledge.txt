Project concept
BT Pathfinder is a terminal-native, AI-assisted identity security investigation experience inspired by BeyondTrust-style identity risk logic.
It is not a generic chatbot.
It is an investigation console for a security analyst.

The CLI should:
- feel operational and credible
- stay mostly text-first
- use light visual hierarchy and small purposeful visualizations
- avoid heavy dashboard layouts, sidebars, split panes, and large widget trees
- use only minimal Textual enhancements where useful
- support arrow-key selection and Enter for next actions
- keep next actions context-aware, not static

Global design rules
1. Keep the UI mostly terminal-native and text-dominant
2. Use muted, normal, and highlight text hierarchy
3. Only add visualization when it directly helps answer the current analyst question
4. Do not add decorative charts
5. Do not overuse Textual layout features
6. Keep sections concise and scannable
7. Each screen should feel like a focused investigation result, not a dashboard
8. The selected action should always be visually clear but minimally styled
9. “Next actions” must change by screen and investigation state
10. Navigation / return actions should appear last
